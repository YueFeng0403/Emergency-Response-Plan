# Emergency-Response-Plan-for-Public-Health-Emergencies-in-the-Community

本仓库用于存放社区突发公共卫生事件应急方案生成研究的补充材料，以更完整地展示所提出方法的应用过程和研究结果。

受论文篇幅限制，部分完整任务体系、不同典型情景下的应急响应方案矩阵、资源需求属性等未在正文中全部展示，相关材料统一收录于本仓库。

## Repository Contents

| 文件 | 内容 |
| --- | --- |
| `应急任务扩展列表.csv` | 一级应急任务及基于承灾体状态进一步扩展形成的二级应急任务 |
| `局部扩散情景应急方案.csv` | 局部扩散情景下的社区应急响应方案矩阵 |
| `全面传播情景应急方案.csv` | 全面传播情景下的社区应急响应方案矩阵 |
| `案例社区承灾体详细信息.csv` | 案例社区中“人”与“场所”等承灾体及其状态的详细信息 |
| `资源需求属性.xlsx` | 应急资源属性的详细信息 |
| `应急主题.xlsx` | 应急主题定义及分类边界 |

## Notes

应急方案矩阵以承灾体态势为行、应急主体为列，并在单元格中记录相应主体需要执行的应急任务。应急任务对应的主题及资源信息可依据五层方案网络中的关联关系进一步追溯。
